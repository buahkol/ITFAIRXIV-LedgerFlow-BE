## 🎉 Selamat Datang di LedgerFlow Backend! 🎉

Project ini merupakan backend service yang dibangun menggunakan **Node.js**, terintegrasi dengan modul **AI berbasis Python**, menggunakan **MySQL** sebagai database, dan memiliki fitur **Blockchain** berbasis **Solidity**.

## 🚀 **Features**

* Backend REST API menggunakan **Node.js + Express**
* AI module menggunakan **Python** (komunikasi via child process / API)
* Database relational menggunakan **MySQL**
* Smart contract blockchain menggunakan **Solidity**
* Struktur backend modular dan mudah dikembangkan
* Port default: **5000**

❤️ Keterkaitan dengan Frontend
Backend ini adalah jantung dari aplikasi LedgerFlow. Ia menyediakan semua data yang dibutuhkan oleh [LedgerFlow FrontEnd](https://github.com/keisha-sakura/ITFAIRXIV-LedgerFlow-FE.git). Pastikan backend ini berjalan sebelum Anda menyalakan frontend-nya ya!
